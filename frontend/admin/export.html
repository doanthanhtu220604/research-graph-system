Xuất dữ liệu

Vui lòng chọn định dạng tệp tin bạn muốn xuất và tải về:

Microsoft Excel (.xlsx)
Định dạng chuẩn mới, hiển thị tối ưu cột rộng, dễ đọc, khuyên dùng.
Microsoft Excel 97-2003 (.xls)
Tương thích với các phần mềm và phiên bản Office cũ hơn.
Comma-Separated Values (.csv)
Tệp văn bản thuần phân tách bằng dấu phẩy, dùng truyền dữ liệu.
